# Playbook: Next Best Move

**Task:** The coach asks "what should I do with this client?" The brain diagnoses and recommends the single highest-leverage next move, with the reasoning and a fallback.

**Load:** client record + `knowledge/behavior-coaching/04_client_situations_playbook.md` + `knowledge/behavior-coaching/03_adherence_and_retention.md` + relevant training/nutrition docs + `ahmed-method/07_client_handling_and_retention.md`.

## Method (diagnose before prescribing)
1. **Classify the situation.** Is this a training, nutrition, adherence/psychology, life-circumstance, or business (renewal/pricing) issue? Most "plateaus" are actually adherence or recovery, not programming.
2. **Check the data.** What do the trends say vs what the client feels? Reconcile the two.
3. **Find the real constraint.** The bottleneck is usually one thing: sleep, stress, protein, consistency, or an unrealistic expectation. Fix the constraint, not the symptom.
4. **Pick ONE move.** Resist changing five variables. One clear action the coach and client can execute this week.

## Output format
```
DIAGNOSIS: [what's actually going on, 1-2 lines]
WHY: [the evidence — trend + likely cause]
BEST NEXT MOVE: [one specific action]
HOW TO DELIVER IT: [in Ahmed's voice — draft the message or talking point]
IF THAT DOESN'T LAND: [fallback move]
DON'T: [the tempting-but-wrong move to avoid, e.g. "don't slash calories again"]
```

## Rules
- Bias to the **smallest change that works**. Coaches over-adjust; adherence beats optimization.
- If the issue is psychological (motivation, body image, comparison), route to `motivational_interviewing` techniques, not a program change.
- If it's clinical (pain, disordered eating, medical), the best move is **refer out** — say so plainly.
- Always give the coach the **words to use**, in Ahmed's voice, not just the strategy.
