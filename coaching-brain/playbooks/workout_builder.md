# Playbook: Workout / Program Builder

**Task:** Design or adjust a training program for a client from their goals and constraints.

**Load:** `knowledge/training/02_program_design.md` + the goal-specific doc (`03_hypertrophy_and_strength.md`, `04_fat_loss_and_recomp_training.md`, `05_running_and_endurance.md`, `06_hyrox_and_hybrid.md`), `07_special_populations_and_injuries.md` + `ahmed-method/04_programming_approach.md`.

## Required inputs (ask for any missing)
Primary goal (+ any secondary, e.g. "fat loss + run a half") · training age/experience · days/week available + session length · equipment access (gym / home / bands) · injuries or pain · other activities to fit around (run club, calisthenics, swimming, classes) · schedule constraints · wearable data.

## Build sequence
1. **Needs analysis** → map goal to the right template (strength / hypertrophy / fat-loss+recomp / run / HYROX / hybrid).
2. **Set the week**: split by days available; blend strength + running/conditioning without interference (per the hybrid doc); protect recovery.
3. **Select exercises** by goal, equipment, and injury history; substitute around limitations (knee/back/shoulder mods).
4. **Prescribe** sets × reps × intensity (RPE/RIR) with clear progression rules (double progression, weekly volume landmarks, deload timing).
5. **Integrate the client's other activities** (Ahmed always fits swimming/calisthenics/run club in, not against them).
6. **Progress + deload**: state how it advances over the 12 weeks and when to back off.

## Output format
```
PROGRAM: [goal] — [X days/week, Y weeks]
WEEK STRUCTURE: [day-by-day: focus + key lifts/runs]
PROGRESSION: [how load/volume advances + deload week]
INJURY/EQUIPMENT ADAPTATIONS: [subs made and why]
FITS AROUND: [their run club / class / swim]
HOW TO COACH IT: [what to tell the client, in Ahmed's voice]
TRACK: [what to log; when to reassess]
```

## Guardrails
- Scale for beginners; never prescribe advanced volume/intensity to a novice.
- Pain is not "push through it" — if there's pain, injury, or a red flag, modify and **refer to a physio/doctor**.
- Programs are hypotheses; adjust from performance and recovery data.
